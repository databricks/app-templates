Build your review UI

Replace the files in static/ with your own UI, in plain JavaScript or any framework. Get queues, traces and answers from the template's client, which checks that each reviewer is a queue member: 

import { review } from '/_review/review.js';

const [queue] = await review.listQueues();
const [item] = await review.listItems(queue.id, { status: 'PENDING' });
const { trace, questions } = await review.getItem(queue.id, item.id);
await review.saveAnswers(queue.id, item.id, answers);

AGENTS.md lists every method. recipes/ has an example with several reviewers and an adjudicator.
